Structural  Prgramming will follow top down approach where as FUnctional programming follow bottom-up approach
strcutural programming will focus on process where as functional programming will focus on data.

How to create Stream API??

Stream Api is used to achieve FUnctional programming
Stream API ->>Intermediate operations + terminal operations
Stream API will not modify the data why because stream Api will not store any data.
Stream Api will capture data from source
Source may be Arrays or collections

Stream APi is divided into 2 types::

  a.sequential Stream API
  b.Parallel Stream API

  Stream Creation::
  ----------------
  Arrays.stream()
  COllectionObject.stream()
  Stream.empty()
  stream.of()

  Stream API divided into 3 types

  Arrays --->Stream --Operations
  List/Set-->Stream --Operations
  Map     -->Stream --Operations

 ------------------------------------------------------------------------
 STREAM API is combination of->Intermediate operations + Terminal Operations
| Operation            | Description                                                                     | Example                               |
|----------------------|---------------------------------------------------------------------------------|---------------------------------------|
| filter()             | Selects elements based on a condition.                                          | stream.filter(n -> n > 10)            |
| map()                | Transforms each element into another form.                                      | stream.map(String::toUpperCase)       |
| flatMap()            | Flattens nested collections into a single stream.                               | list.stream().flatMap(List::stream)   |
| distinct()           | Removes duplicate elements.                                                     | stream.distinct()                     |
| sorted()             | Sorts elements in natural or custom order.                                      | stream.sorted()                       |
| peek()               | Performs an action on each element without modifying it (mainly for debugging). | stream.peek(System.out::println)      |
| limit()              | Returns the first `n` elements.                                                 | stream.limit(5)                       |
| skip()               | Skips the first `n` elements.                                                   | stream.skip(2)                        |
| takeWhile() (Java 9+) | Takes elements while a condition is true.                                      | stream.takeWhile(n -> n < 10)         |
| dropWhile() (Java 9+) | Drops elements while a condition is true.                                      | stream.dropWhile(n -> n < 10)         |
|----------------------|---------------------------------------------------------------------------------|---------------------------------------|

**Terminal Stream Methods (Java):
-->Terminal operations will produce final results
 | Operation            | Description                                                          | Example                                     |
 |----------------------|----------------------------------------------------------------------|---------------------------------------------|
 | forEach()            | Performs an action on each element.                                  | stream.forEach(System.out::println)         |
 | forEachOrdered()     | Performs an action on each element while preserving encounter order.  | stream.forEachOrdered(System.out::println) |
 | collect()            | Collects stream elements into a collection or another data structure. | stream.collect(Collectors.toList())        |
 | toArray()            | Converts the stream into an array.                                   | stream.toArray()                            |
 | reduce()             | Combines all elements into a single result.                          | stream.reduce(Integer::sum)                 |
 | count()              | Returns the number of elements in the stream.                        | stream.count()                              |
 | min()                | Returns the smallest element according to a comparator.              | stream.min(Integer::compareTo)              |
 | max()                | Returns the largest element according to a comparator.               | stream.max(Integer::compareTo)              |
 | findFirst()          | Returns the first element of the stream.                             | stream.findFirst()                          |
 | findAny()            | Returns any element from the stream (useful for parallel streams).   | stream.findAny()                            |
 | anyMatch()           | Returns true if at least one element matches the given condition.    | stream.anyMatch(n -> n > 10)                |
 | allMatch()           | Returns true if all elements match the given condition.              | stream.allMatch(n -> n > 0)                 |
 | noneMatch()          | Returns true if no elements match the given condition.               | stream.noneMatch(n -> n < 0)                |
 |----------------------|---------------------------------------------------------------------------------|----------------------------------|
